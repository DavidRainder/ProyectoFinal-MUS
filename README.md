# Proyecto Final Informática Musical (MUS - GDV - UCM)

Dentro de la carpeta 'Build' se encuentra una build con la aplicación desarrollada en Unity. Al ejecutar el archivo "ProyectoFinal-MUS.exe" se abrirá la aplicación.
Para interactuar con los pilares, hay que acercarse y pulsar la 'E' cuando aparezca un texto descriptivo del botón.
